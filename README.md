# Предупреждён — Новороссийск

Прототип сайта против мошенников для УМВД России по г. Новороссийску.

- `index.html` — сайт для жителей (новости, архив схем, что делать, памятки, поделиться, личный кабинет).
- `smi.html` — кабинет СМИ (вход по логину и паролю, анкета по QR).
- `admin.html` — панель управления УМВД (статистика и отчёты, материалы, проверка, учётные записи, разделы, подписчики, рассылка).

Сейчас это демо: данные хранятся в браузере. Рабочая версия — на Amvera (Docker, данные в `/data`).

Тестовые входы: СМИ `ivanova` / `nvr2026`, администратор `admin` / `admin2026`.
