# Предупреждён — Новороссийск

Прототип сайта против мошенников для УМВД России по г. Новороссийску.

- `index.html` — сайт для жителей (новости, архив схем, что делать, памятки, поделиться, личный кабинет). Ссылок на панель нет.
- `admin.html` — закрытая панель управления. Вход только по логину и паролю, которые выдаёт администратор. Регистрации нет.
  - администратор — статистика и отчёты, материалы, проверка, учётные записи, разделы, подписчики, рассылка;
  - сотрудник — добавляет новости, памятки, схемы и видит свои материалы.

Сейчас это демо: данные хранятся в браузере. Рабочая версия — на Amvera (Docker, данные в `/data`).
